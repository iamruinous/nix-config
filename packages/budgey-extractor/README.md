# budgey-extractor

Offline OpenCode session extractor for Postgres + Weaviate.

## Features

- Ingest OpenCode session data into PostgreSQL for budget tracking
- Index session transcripts into Weaviate for semantic search
- Reads project registry from `~/.config/ruinagents/budgey/projects.json`

## Commands

```bash
# Ingest sessions into Postgres
budgey-extractor ingest-postgres --dsn "postgresql://user:pass@host/db"

# Ingest sessions into Weaviate
budgey-extractor ingest-weaviate --weaviate-url "http://localhost:8080"
```

## Usage

Add `budgey-extractor` to `environment.systemPackages`:

```nix
environment.systemPackages = [ pkgs.budgey-extractor ];
```

## Registry

The extractor reads project metadata from the registry file generated by `opencode-projects` module at:

`~/.config/ruinagents/budgey/projects.json`
