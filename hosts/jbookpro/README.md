# jbookpro

MacBook Pro running nix-darwin with development tools.

## Hardware

- **Model**: 14-inch MacBook Pro (Space Black)
- **Platform**: aarch64-darwin (Apple Silicon)
- **Chip**: Apple M4 with 10-Core CPU and 10-Core GPU
- **Memory**: 32 GB unified memory
- **OS**: macOS

## Key Features

### Development Environment
- Developer tools and environment configured
- nix-darwin for declarative macOS configuration

### User Configuration
- Primary user: jmeskill
- Home directory: /Users/jmeskill

## Purpose

Personal MacBook Pro for development work. Configured with essential developer tools and utilities for software development on macOS.
