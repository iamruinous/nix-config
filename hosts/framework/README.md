# framework

Framework laptop running NixOS with KDE Plasma 6 desktop environment.

## Hardware

- **Model**: Framework Laptop 13
- **Platform**: x86_64-linux
- **CPU**: Intel Core Ultra 5 125H (14 cores, Framework-specific hardware support)
- **Memory**: 32 GB DDR5-5600
- **Graphics**: Intel Arc integrated graphics with 32-bit support
- **Storage**: 1TB NVMe, Btrfs filesystem with separate EFI and boot partitions
- **Security**: Secure Boot via Lanzaboote
- **Biometrics**: Fingerprint reader for authentication

## Key Features

### Desktop Environment
- KDE Plasma 6 desktop
- Wayland session variables configured
- Boot splash screen (Plymouth)

### Applications & Services
- Steam gaming platform
- Flatpak support
- Dwarf Fortress
- 1Password integration
- Printing support with network printer discovery

### Security
- Secure Boot enabled with Lanzaboote
- Fingerprint authentication for login
- Polkit security framework

### System Configuration
- Developer tools and environment
- Framework-specific hardware optimizations
- Firmware updates via fwupd
- Dual clock support (hardware clock in local time)

## Purpose

Personal laptop for daily use, gaming, and development work. Configured with desktop productivity tools and gaming support.
